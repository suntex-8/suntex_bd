4.2 Testing & Evaluation

  1. MCQ answer key with shuffled options (fixed seed)
  2. Model's answer choice recorded
  3. Token entropy & probability from generation scores
  4. Answer-level UQ = mean token entropy
  5. Confidence = option probability (calibration)
  6. 5 stochastic responses → semantic analysis
  7. Encode → cosine similarity → clustering → normalized semantic entropy
  8. AUROC/AUPRC vs. correctness; ECE, Brier, NLL
  9. Cross-model validation: Llama ↔ Qwen
  10. Mistral ↔ Gemma cross-validation

4.3.1 Token & Answer Uncertainty

H(P) = − Σ pᵢ · log(pᵢ)
Answer UQ = (1/n) Σ H(token)

Example: if token entropies = 0.20, 0.40, 0.30 → Answer UQ = 0.30 (illustrative only).

4.3.2 Semantic Uncertainty

all-MiniLM-L6-v2 on 5 stochastic responses.

  • Pairwise cosine similarity
  • Cluster responses with similarity ≥ 0.80
  • Semantic entropy: H = − Σ pᵢ log(pᵢ) (pᵢ = cluster proportions)
  • Normalized by log(k)

One cluster → UQ = 0; uniform clusters → higher uncertainty.

4.4 Summary

Partial pipeline implemented: deterministic token/answer uncertainty, stochastic semantic uncertainty, calibration, uncertainty-based error discrimination, bidirectional cross-model validation for two SLMs (Llama & Qwen) plus Mistral/Gemma. Missing: claim-level, multi-model expansion, broader benchmarks.

5.3.1 Complex Engineering Problem

Multi-level uncertainty (token, answer, semantic) paired with correctness. Pipeline includes next-token distributions, entropy, stochastic generation, embeddings, clustering, calibration metrics, and cross-model validation. Resource-intensive due to repeated generation.

📐 Software Standards

Modular Python, CSV results, explicit seed, checkpointing, open-source libraries. Five-step pipeline: Data Prep → Inference → Uncertainty → Semantic → Evaluation.

⚙️ Hardware Standards

4-bit NF4 quantization, automatic device mapping, consumer GPU / cloud notebook friendly.

🌍 Design Constraints

Economic: open-source, compute time main cost.
Environmental: quantization + checkpointing.
Ethical: not a fact-checking tool — measures uncertainty.
Social: expert-level GPQA, not for other domains/languages.

♻️ Sustainability & Future

Checkpointing, quantization, modular invocation reduce repeated computation. Future: compute efficiency, larger scale deployment, claim-level verification.
